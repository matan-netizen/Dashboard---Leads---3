# דאשבורד ניהול לידים

<div dir="rtl">

דאשבורד לניהול לידים של העסק, מחובר לטבלת הלידים ב-Airtable: משפך מכירה, רשימת "לטיפול היום", טבלה עם חיפוש וסינון, לוח Kanban עם גרירה, עריכת לידים ופנייה מהירה בוואטסאפ עם תבניות ההודעות.

| מסמך | תוכן |
|---|---|
| [`SPEC.MD`](./SPEC.MD) | האפיון המלא – מקור האמת |
| [`Practice.md`](./Practice.md) | הנחיות, תהליך עבודה, יומן שלבים ופקודות הפעלה |
| [`agent/SPEC.md`](./agent/SPEC.md) | אפיון "עוזר הלידים" – סוכן AI: איך הוא פועל, כלים, ניהול זיכרון |

## התחלה מהירה

```bash
npm install
cp .env.example .env     # ממלאים AIRTABLE_TOKEN (אופציונלי – בלי טוקן עובד על נתוני דמה)
npm run dev              # http://localhost:5173
```

פירוט מלא – [`Practice.md` סעיף 5](./Practice.md#5-פקודות-הפעלה).

## פרטיות
הריפו ציבורי ולכן **לא מכיל נתוני לידים אמיתיים**. הנתונים נטענים מ-Airtable בזמן ריצה, והטוקן לעולם לא נשמר בריפו:
- **בפיתוח מקומי** – דרך פרוקסי של Vite, עם הטוקן מ-`.env`.
- **באתר החי (GitHub Pages)** – לוחצים "חיבור ל-Airtable" ומדביקים את הטוקן. הוא נשמר רק ב-localStorage של אותו דפדפן, והבקשות יוצאות ישירות ל-Airtable. "התנתקות" מוחקת אותו.
